# plumbline.nl

Static website for Plumbline, hosted on GitHub Pages.

- Served from the `main` branch, repository root.
- `CNAME` binds the site to `plumbline.nl`; do not delete it.
- `.nojekyll` disables Jekyll processing, so files are served as-is.

Edit `index.html` and `style.css`, commit, push — the site updates within a minute or two.
